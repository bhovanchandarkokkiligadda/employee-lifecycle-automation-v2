# ServiceNow Employee Lifecycle Automation - Demo Script

## Demo Objective

Demonstrate the complete employee onboarding and offboarding lifecycle using ServiceNow.

The demonstration shows how a request moves from Service Catalog submission through approval, task execution, SLA monitoring, notifications, and final completion.

## 1. Introduction

Begin by introducing the application:

> This project is a ServiceNow Employee Lifecycle Automation system designed to streamline employee onboarding and offboarding processes.

Mention the main technologies and capabilities:

- ServiceNow Service Catalog
- Flow Designer
- Approval workflows
- Task management
- SLA monitoring
- Notifications
- Role-based access
- Employee lifecycle tracking

---

## 2. Open the Service Portal

Navigate to the ServiceNow employee/service portal.

Show the available services.

Navigate to:

```text
Service Catalog
    ↓
HR Services
    ↓
Employee Lifecycle Services
````

---

## 3. Demonstrate Employee Onboarding

Open the employee onboarding request.

Show the form fields.

Enter the required employee information.

Explain that the dynamic form collects the information required to initiate the onboarding process.

Submit the request.

Capture the generated request number.

---

## 4. Demonstrate Approval

Open the submitted request.

Show that the request requires approval.

Demonstrate the approval process.

Explain:

> The approval stage ensures that employee lifecycle requests are reviewed before downstream tasks are executed.

Approve the request.

---

## 5. Demonstrate Automatic Task Creation

After approval, show the tasks generated by the workflow.

Example tasks may include:

* HR task
* IT task
* Manager task
* Access/setup task
* Equipment-related task

Explain that Flow Designer automates task generation and lifecycle processing.

---

## 6. Demonstrate Task Management

Open one of the generated tasks.

Show:

* Assigned user
* Task status
* Priority
* Due date
* Related request

Update the task status.

Complete the task.

---

## 7. Demonstrate SLA Monitoring

Open the relevant request or task.

Show the SLA information.

Explain:

> SLA monitoring helps track whether lifecycle activities are being completed within the defined service target.

Show the SLA status and timing information available in the application.

---

## 8. Demonstrate Notifications

Show the notifications generated during the lifecycle.

Explain that notifications can inform:

* Employees
* Managers
* HR users
* Task assignees

Demonstrate the notification related to the request, approval, or task.

---

## 9. Demonstrate Request Completion

Return to the original employee lifecycle request.

Show the lifecycle progression:

Submitted
   ↓
Approval
   ↓
Approved
   ↓
Tasks Created
   ↓
Tasks Completed
   ↓
Request Completed

Show the final request state.

Explain that the completed lifecycle provides traceability from the original request through all related activities.


## 10. Demonstrate Offboarding

Repeat the process for an employee offboarding request.

Navigate to:

Service Catalog
    ↓
HR Services
    ↓
Employee Offboarding

Submit an offboarding request.

Show the approval.

Show generated tasks.

Demonstrate task completion.

Show the final request closure.

---

## 11. Source Control Demonstration

Open the GitHub repository.

Show:

* `docs/`
* `project-report/`
* `screenshots/`
* `update-set/`
* `README.md`

Explain that the ServiceNow application is connected to GitHub through ServiceNow Studio Source Control.

Show the commit history and merged Pull Request.

---

## 12. Closing Statement

End the demonstration with:

> The ServiceNow Employee Lifecycle Automation application provides an end-to-end workflow for employee onboarding and offboarding, combining Service Catalog, approvals, Flow Designer automation, task management, SLA monitoring, notifications, role-based access, and source control.
