# Demo Guide

## Application Demonstration

The demonstration shows the complete employee lifecycle workflow from request submission to completion.

## Demo Flow

### 1. Open Service Catalog

Navigate to:

ServiceNow → Service Catalog

Open the HR Services category.

### 2. Employee Onboarding

Open:

HR Services → Onboard Employee

Enter the required employee information.

Submit the request.

### 3. Approval

Open the submitted request and demonstrate the approval process.

Show:

- Request number
- Requested employee
- Request status
- Approval status
- Approver
- Approval activity

Approve the request.

### 4. Task Creation

After approval, demonstrate that the required employee lifecycle tasks are generated.

Show:

- Task number
- Task description
- Assigned group or user
- Task status
- Due date
- Related request

### 5. SLA Monitoring

Open the relevant task and demonstrate SLA information.

Show:

- SLA definition
- Start time
- Due time
- SLA status
- Remaining time or elapsed time

### 6. Notifications

Demonstrate notifications generated during the workflow.

Examples include:

- Request submission notification
- Approval notification
- Task assignment notification
- Completion notification

### 7. Employee Lifecycle Tracking

Show the employee lifecycle information and related tasks.

Demonstrate how the request progresses through its lifecycle.

### 8. Request Completion

Complete the required tasks and update the request status.

Show the final state of the request.

The expected lifecycle is:

Submitted → Approval → Approved → Tasks Created → Tasks Completed → Request Completed

## Offboarding Demonstration

Repeat the workflow using:

Service Catalog → HR Services → Offboard Employee

Demonstrate:

- Offboarding request
- Approval
- Task generation
- SLA monitoring
- Notifications
- Completion

## Final Demonstration Checklist

- [ ] Service Catalog opened
- [ ] HR Services opened
- [ ] Onboarding request submitted
- [ ] Approval demonstrated
- [ ] Tasks generated
- [ ] SLA information shown
- [ ] Notifications demonstrated
- [ ] Employee lifecycle tracked
- [ ] Request completed
- [ ] Offboarding workflow demonstrated
